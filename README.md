# Doorstep downloads

**Doorstep puts your Ring doorbell and cameras on your Mac.** This repository holds the downloads and the update feed. The app, guides and source code live at **[github.com/iinde/doorstep](https://github.com/iinde/doorstep)**.

## Download
**[Get the latest version](https://github.com/iinde/doorstep-releases/releases/latest)** (the `.dmg` file), open it, and drag Doorstep into Applications.

The first time, macOS may say it can't check the app: open **System Settings › Privacy & Security** and click **Open Anyway**. You only do this once, and Doorstep updates itself after that.
